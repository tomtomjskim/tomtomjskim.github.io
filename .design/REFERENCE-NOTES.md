# 포트폴리오 리디자인 참고 메모

이 문서는 현재 운영 사이트의 콘텐츠 원천이 아니라, 리디자인 검토용 메모입니다.

## 참고한 방향

- Lee Robinson: 짧은 자기소개와 콘텐츠 목록 중심. 별도의 홍보형 Hero나 프로젝트 카드 그리드가 핵심이 아님.
- Patrick Collison: 인덱스형 개인 사이트. 첫 화면에서 링크와 정보 구조가 바로 보임.
- Maggie Appleton: 글과 주제를 분류해 긴 콘텐츠를 읽기 쉽게 구성.
- Rauno Freiberg: 시각 효과보다 일관성·속도·세부 완성도를 우선하는 태도만 참고.
- 국내 포트폴리오 큐레이션: 타이포그래피 중심, 절제된 색상, 정돈된 그리드가 정보 전달에 유리하다는 공통점 참고.

## 이번 리디자인에서 제외

- 큰 문장 중심 Hero
- CTA 버튼 묶음
- 2열 프로젝트 카드
- 모든 항목을 ‘대표 사례’로 규정
- 공개 연구·개발 자료와 회사 실무 사례의 동급 배치
- 색상·그림자·둥근 모서리를 이용한 랜딩페이지 연출

## 이번 리디자인 목표

```text
이름과 역할
→ 짧은 경력 요약
→ 업무 사례
→ 공개 개발 자료
→ 작업 방식과 공개 범위
```

홈에서는 사례의 존재와 차이만 빠르게 확인하고, 상세 설명은 각 문서에서 읽도록 한다.
